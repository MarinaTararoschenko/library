AIR DesignSystem

Icon Button

v1.0

Botón de acción compacto que contiene exclusivamente un ícono. Se usa cuando el espacio es reducido o cuando la acción es suficientemente reconocible sin texto. Disponible en 5 variantes visuales y 6 tamaños.

01 Overview

Cuándo usarlo
  • Usar cuando la acción es clara e inequívoca sin texto: cerrar, agregar, buscar, editar.
  • Siempre proveer ariaLabel con una descripción precisa de la acción.
  • Usar primary para la acción más importante, tertiary para acciones secundarias en barras de herramientas.
  • Agrupar Icon Buttons relacionados con separadores visuales para dar contexto.
  • Preferir tamaños M o L en interfaces táctiles (área mínima recomendada: 40px).
Cuándo no usarlo
  • No usar si la acción puede ser ambigua — optar por un air-button con label.
  • No omitir el atributo ariaLabel — los lectores de pantalla lo necesitan.
  • No mezclar variantes primary y danger en el mismo grupo de acciones.
  • No usar tamaño XS en interfaces táctiles — el área de toque sería demasiado pequeña.

05 Accessibility

Criterios base

El componente Icon Button renderiza un <button> nativo. Al no tener texto visible, el atributo ariaLabel es obligatorio para garantizar la accesibilidad con lectores de pantalla.

Especificación técnica
  • ariaLabel: requerido — describe la acción del botón para lectores de pantalla.
  • Teclado: Tab para enfocar, Enter o Space para activar.
  • Foco visible: anillo de 3px con color del tema (--air-color-theme-background-a50).
  • disabled: usa atributo nativo disabled — excluido del orden de Tab.
  • loading: considerar aria-busy="true" en el contenedor padre para notificar el estado.
  • Área táctil mínima: usar tamaño M (40px) o mayor en interfaces móviles.

06 User Guidelines

Do

Agrupar Icon Buttons para acciones relacionadas en barras de herramientas.

Usar primary para la acción más importante del grupo.

Don't

No usar acciones ambiguas sin texto de apoyo cerca — el usuario no sabe qué hace el botón.

No usar XS en mobile — el área táctil de 24px es demasiado pequeña para el dedo.
